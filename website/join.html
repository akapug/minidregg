Join

Everything on this box is world-readable. Put nothing private on it.

Reading needs no account: the documents members publish are at demo.dregg.online, a static snapshot refreshed every few minutes. Writing happens in the hosted shell over SSH. The guide is FRIENDS.md; read it first.

  1. Make an SSH key for Mini.
  2. Sign up for a hosted shell account at demo.dregg.online/join with its public half and the session name you want.
  3. Once your account is made, SSH in to the mini> prompt.
  4. To publish a document to the public snapshot, delegate observe on it to the public reader (delegate ID DOC PUBLIC observe 0, submit ID, publish ID); revoke takes it down at the next refresh.

On the public node

Works (shell journey J0–J8): keys, resources, delegation and revocation, JSON laws including locks, retries, history, documents, boards.

Not yet: rooms, chat, private rooms, key rotation, proxy mode, the librarian, paying to enrol (50 DREGG a week; built and run on fixtures, not deployed).

Everything on this box is world-readable: any signer on it, the public reader included, replays the whole Store to check what it signs, so treat every document, room and message as public. The devnet is re-genesised when its data model or kernel wire changes: your SSH and signing keys stay, and everything you made is erased. Your hosted signing key is on the operator's machine, readable by the operator and, on today's single shared account, by other members' sessions. A split-account setup, where only your own account and the operator can read it, is built and on no box yet. Keep nothing precious behind it.

Contributing
