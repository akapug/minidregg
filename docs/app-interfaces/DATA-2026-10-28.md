## Datasette corrects the earlier read-only claim

The signed package ID is `547714ee1f01bae653fe9276d6d30ce9`. Its downloaded archive's
SHA-256 prefix was checked; this source inspection does not independently verify the
publisher's signature. The extracted package has:

- `datasette_insert/__init__.py`: POST `/-/insert/<database>/<table>` and
  `/-/upsert/<database>/<table>` accept a JSON object or array, with optional `pk`
  and `alter`. The reply has `table_count`.
- `datasette_upload_dbs/__init__.py`: multipart POST `/-/upload-dbs` accepts `db`,
  `db_name`, and `xhr`; XHR success returns `{ok:true,redirect:…}`. It validates a
  SQLite file, persists it and registers a mutable database.
- `datasette_sandstorm_support/__init__.py`: `edit` grants `upload-dbs`,
  `insert:all`, `datasette-write`, and schema editing. Authority still comes from
  the receiving grain's current package permission bits.
- `/opt/app/metadata.yml`: upload directory `/var/databases`.

Datasette 0.63 wraps requests with `asgi_csrf`, cookie `ds_csrftoken`. A prepared GET
and per-route cookie jar plus `x-csrftoken` are needed for browser-cookie writes.
A fixture database upload followed by insert/upsert and SQL JSON readback is the
meaningful write scenario. GET `/-/versions.json` remains a read and cannot count
as write acceptance. Installing plugins in an upstream build script was a lead;
the installed modules above are the package-specific evidence.

## Kiwix upload contract

Exact package `eace6915…` contains `zim_uploader/uploader/app.py`. POST `/upload`
requires `uploader`, multipart `file` ending `.zim`, and text `contentRange` with
`bytes first-last/total`. Final upload becomes `/var/data/kiwix.zim` and starts the
reader. The response is JSON text with Flask's `text/html` MIME, including a
per-file `error` field on failure; status alone is weaker than validating this
structured response. An existing completed library is refused rather than overwritten.
A finite article GET reads the imported library. Large/chunked uploads remain bounded
by both Mini's current body limit and the uploader's 15 MiB request limit.
