## A. Is the thesis right?

**Yes, but its strongest claim is the composition, not the novelty of receipts.** Documents, authority, money, programs and applications occupy one world; a computation can propose a change without acquiring permission to make it. That is stronger than “hosting with explanations.” The datamodel supports this framing: methods grant nothing, policy replacement faces the old law, and transactions face signature, capability and law checks ([AFFORDANCES:458–469](/Users/ember/dev/minidregg/docs/review/2026-10-26-deploy/AFFORDANCES.md:458)).

The striking demonstration is: **“I gave this agent precisely enough authority; then I changed that authority, and its next actual attempt failed.”** The stranger should see the document, grant, attempted change, judgement and purse together. Hermes’s fixed tool catalogue and mediated provider access make this plausible; they also mean the demo must distinguish a tool unavailable to the model from an attempted operation refused by Mini ([AFFORDANCES:395–405](/Users/ember/dev/minidregg/docs/review/2026-10-26-deploy/AFFORDANCES.md:395)).

“Nothing else a stranger has used does that” is unsupported. “Every act leaves a receipt” also overreaches: local help, reads and proposal preparation are not admitted world transitions.

## C. The parity law (§1a)

**The law is right; the proposed mechanism does not exist yet.** `Verb` contains three strings: name, usage, operation. Its catalogue explicitly leaves actual grammars with owning modules ([shell.rs:46–52](/Users/ember/dev/minidregg/native/resource-client/src/shell.rs:46), [109–126](/Users/ember/dev/minidregg/native/resource-client/src/shell.rs:109)). Alternatives, JSON, files, stdin, optional arguments and contextual references cannot reliably become usable fields by splitting help text.

Build one structured command grammar consumed by shell parsing, help and generic form rendering. That follows “emit, never imitate”; a second handwritten web grammar does not ([ATLAS:228–231](/Users/ember/dev/minidregg/ATLAS.md:228)).

Smallest honest `jwebparity`:

- Inventory **leaf actions and argument variants**, including chat/Hermes/story, against rendered controls and handlers.
- Fail by name when a leaf lacks a nonterminal face; verify the checker fails when one mapping is removed.
- Exercise rendered forms through real handlers, checking argument preservation and typed results. Report unexercised leaves separately.
- Cover admitted, refused and undecided outcomes, including exact recovery. Route coverage alone is not behavioral parity.

The proposed web classifier also needs correction: web design §2, lines 80–83 equates exit zero with admitted, but `whoami`, help and history return successful local endings ([shell.rs:2799–2815](/Users/ember/dev/minidregg/native/resource-client/src/shell.rs:2799)). “Prepared,” “read” and “completed locally” need truthful presentation.

Bespoke faces belong to document editing/history/diff/transclusion; grants/delegation/laws; retained attempts/recovery; rooms/residents/purses; boards; and story navigation. Generic structured forms can carry the remaining capability without becoming a pasted-command box.

The no-JavaScript promise must describe Mini’s own forms. It does not establish that arbitrary installed applications or the xterm terminal work without JavaScript.

## D. “The box is a member” (§2)

**Sound as accountable publication; theatre as proof of host operations.** A signed admitted post proves that the box identity posted a report. It does not prove a restart occurred, a backup restores, or a measurement was collected correctly. Nor does putting root’s reports into Mini place root’s actions under Mini admission.

Publish narrowly scoped records: candidate, event, measurement conditions, artifact digest, result, and links to appropriately public evidence. Label reported facts as reports. Missing ticks must remain missing, not silently become success.

The room must never contain raw journals, environment dumps, command transcripts, private conversation, enrollment/session links, capability-bearing invitations, provider credentials, DNS tokens, backup decryption material or private dataset contents. Such data could leak both authority and user information. The web design explicitly says a member body reaches the world-readable Store (§2, lines 103–108); a public-room label is no substitute for sanitizing at production.

Give the box identity only the grants needed to append these reports. Performance publication remains mandatory; elaborate self-narration does not.

## E. The ambitions A0–A9

My provisional order by tour value per day is:

| Rank | Ambition | Reason |
|---|---|---|
| 1 | A1 browser join | Removes the absolute entry barrier. |
| 2 | A4 guided tour | Makes every subsequent capability discoverable and composable. |
| 3 | A2 agent under law | Delivers the central experience. |

| 5 | A8 member-defined kinds | Demonstrates *programmable* rather than merely configurable. |
| 6 | A7 story/markets evidence | Story offers immediate, visible rules; markets need more explanation. |
| 7 | A5 application breadth | Valuable compatibility, but diminishing introductory payoff after one convincing app. |
| 8 | A6 oracle | Distinctive if its checked claim is understandable; otherwise another opaque application. |
| 9 | A3 operations room | Trust support, little direct agency. |
| 10 | A9 second node | Substantial integration for a largely invisible first-visit benefit. |

These are judgement calls, not measured effort estimates.

**Drop A3 and A9 as separate tour ambitions.** Keep required performance publication and concise operational evidence; retain transport work and existing capabilities. This changes emphasis, not the all-surfaces opening contract or the rescue-before-deletion rule.

Missing: let a stranger modify a small law, observe its effect on an existing grant, and inspect preserved earlier history. Pair that with lost-reply recovery. “I changed the rules of this shared place, watched my agent encounter them, and recovered an interrupted action without duplicating it” is the experience worth building.
